PNT → WAB-R Estimator

Estimates every WAB-R subtest, the composites and the Aphasia Quotient from Philadelphia Naming Test accuracy, each with a calibrated prediction interval.

An adjunct, not a replacement. Production subtests are estimated with useful precision; auditory comprehension is not, especially in severe aphasia. Not a diagnostic device. All computation happens in your browser; no data are sent anywhere.

PNT response counts

Error counts are optional. When entered, they must add up to the items administered together with the correct responses. Estimates are based on naming accuracy (correct / items administered): in the validation study, error types did not improve the WAB-R estimates. The error profile is shown for your records.

The model was developed on the full 175-item PNT. With a different number of items, the estimate uses the proportion correct and has not been validated.

How estimates are made

For each of the 10 WAB-R subtests, a ridge-penalised fractional-logit model maps PNT naming accuracy (logit accuracy with quadratic and cubic terms) to the expected score on the subtest's own 0-to-maximum scale. The composites (Spontaneous Speech, Auditory Verbal Comprehension, Naming & Word Finding) and the AQ are computed from the estimated subtests with the WAB-R formulas, so a profile is always internally consistent. Only total correct is used: error types added no meaningful accuracy in nested cross-validation.

Intervals are normalised conformal prediction intervals: the estimate ± a stored quantile of cross-validated, scale-normalised errors, so intervals narrow near the floor and ceiling of each subtest. Only one aggregate quantile per outcome is stored; the model file contains no participant-level values. In cross-validation, 90% intervals covered the true score in 90–91% of cases on average, but coverage varied with severity (below).

Intended use and limits

  • Developed in 213 English-speaking adults with post-stroke aphasia beyond the early recovery period, assessed with the PNT and WAB-R within one week, at a single centre. Not yet externally validated.
  • Production subtests (Object Naming, Information Content, Responsive Speech, Naming & Word Finding) are estimated with useful precision. Auditory comprehension is not, and comprehension intervals under-cover in severe aphasia: administer those subtests directly.
  • The AQ is estimated with a mean absolute error of about 7 points, larger than typical benchmarks of meaningful change, so the tool is not suitable for tracking an individual's change over time.
  • Estimates describe groups of similar patients; an individual's true score can fall outside the interval.
